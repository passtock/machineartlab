2. 배선표

다이어그램의 9번 '17'은 "위에서 9번째 핀, 실크 인쇄 글자 17"이라는 뜻입니다. 보드 뒷면 헤더의 실크 인쇄 글자를 보고 꽂으면 됩니다. 번호는 위(3.3V)에서부터 센 물리적 순서입니다.

4. 주의 사항

5V 전원 (WB-B). 보드는 UART 표시 USB-C 포트로 전원을 넣고, MAX7219·ST7789의 VCC는 J3 '5V'(21번)에서 가져갑니다. 두 USB-C 포트의 VBUS는 회로도상 모두 보드 내부 5V 레일(USB-5V)로 모입니다. 다만 21번 핀은 회로도(20핀 버전)에 나오지 않으므로, 부품을 꽂기 전에 보드만 USB로 켠 상태에서 멀티미터로 J3 '5V'–GND 사이가 약 5V인지 확인하세요.

전류. 4.3" 백라이트 포함 보드 약 0.3~0.5A, MAX7219 8자리 최대 약 0.3A, 2.8" LCD 약 0.1A로 합계 최대 1A 가까이 됩니다. PC USB 포트(0.5A)로는 부족할 수 있으니, 전시용으로는 5V 2A 이상 어댑터와 데이터 겸용이 아닌 짧은 고품질 USB-C 케이블을 권장합니다. 업로드할 때만 PC에 연결하세요.
MAX7219 로직 레벨. 5V로 구동하는 MAX7219의 입력 HIGH 기준은 3.5V라서 ESP32의 3.3V 신호로는 아슬아슬합니다. 보통은 동작하지만 숫자가 깨지거나 안 켜지면, MAX7219로 가는 DIN·CLK·CS 3가닥에만 74AHCT125 레벨시프터를 넣으세요. SD와 ST7789 쪽 배선은 그대로 둡니다.
J2 '18'(14번)은 쓰지 않습니다. 회로도상 이 핀은 터치 INT(CTP_INT)이고, GPIO18과는 저항 R33(미장착일 수 있음)을 거쳐야만 연결됩니다. 부저를 달고 싶으면 멀티미터로 J2 14번과 GPIO18이 통전되는지 확인한 뒤, pins.h의 PIN_BUZZER를 18로 바꾸세요.
터치는 비활성화됩니다. 터치 칩의 리셋 핀(GPIO38)을 HX711 SCK로 쓰기 때문입니다. 나중에 터치가 필요해지면 배선을 다시 설계해야 합니다.
점퍼선 길이. SPI 공유선(11, 12번)은 짧을수록 좋습니다(20cm 이내 권장). 화면이 깨지면 lgfx_displays.h의 freq_write를 27MHz에서 20MHz로 낮추세요.

5. 연결·테스트 순서 (하나씩)

  1. 보드만 연결하고 업로드 — 4.3" 화면에 "SD Card Error!"가 나오면 정상입니다(아직 카드 없음). 시리얼 모니터에 [HX711] 응답 없음이 나오는 것도 정상입니다.
  2. MicroSD 삽입 — FAT32로 포맷하고 /images/*.jpg(800×480 권장)를 넣은 뒤 리셋하면 사진이 뜹니다.
  3. 2.8" ST7789 연결 — "MACHINE ART LAB" 헤더와 READY 상태가 보이면 정상입니다. 색이 반전되면 invert를, 빨강·파랑이 바뀌면 rgb_order를 수정하세요.
  4. MAX7219 연결 — 부팅할 때 88888888, 그 뒤 --------가 표시되면 정상입니다.
  5. HX711 + 로드셀 연결 — 정보 LCD의 LOAD 바와 raw 값이 손으로 누를 때 움직이면 정상입니다. 반응 기준은 main.cpp의 TRIGGER_THRESHOLD(기본 8000)로 조정합니다.

업로드: VS Code에서 PlatformIO로 Interactive_VIEWE 폴더를 열고 Upload를 누르거나, 아래 명령을 실행하세요. 보드의 UART 표시 USB-C 포트에 연결해야 합니다.
pio run -d Interactive_VIEWE -t upload
