# [머신아트랩] ESP32 스마트 디스플레이 단독(All-in-One) 인터랙티브 시스템 가이드

본 프로젝트는 **별도의 베이스 컨트롤러(아두이노 등) 없이**, 고성능 **ESP32 스마트 디스플레이 보드 1대**에 로드셀 센서와 8자리 세그먼트를 직결하여 모든 인터랙션을 단독 처리하는 가장 단순하고 안정적인 아키텍처입니다.

---

## 1. 전체 시스템 구조도 (단일 ESP32 직결 방식)

```mermaid
flowchart LR
    subgraph Power["전원 공급"]
        USB[5V 3A Type-C 케이블]
    end

    subgraph ESP32_Display["ESP32 스마트 디스플레이 모듈 (통합 제어기)"]
        CPU[ESP32 / ESP32-S3 CPU]
        LCD[IPS LCD 패널\n800x480 등]
        SD[온보드 MicroSD 카드\n/images 무작위 사진]
        CPU <--> LCD
        CPU <--> SD
    end

    subgraph Sensor["입력"]
        LC[100mm 원판 + 5kg 로드셀] --> HX[HX711 앰프 모듈]
    end

    subgraph Output["출력"]
        SEG[MAX7219 8자리 7세그먼트\n'띠리리리' 롤링 애니메이션]
        BZ[패시브 부저 (선택)\n상승 피치 효과음]
    end

    USB -->|5V 전원| ESP32_Display
    HX -->|DOUT, SCK (2가닥)| CPU
    CPU -->|DIN, CS, CLK (3가닥)| SEG
    CPU -.->|PWM (선택)| BZ
    ESP32_Display -->|5V, GND 공유| HX
    ESP32_Display -->|5V, GND 공유| SEG
```

## 2. 하드웨어 배선표 (5가닥 직결)

디스플레이 보드 뒷면의 확장 커넥터(IO 포트 헤더)에 점퍼선을 직결합니다.

| 부품 | 부품 측 핀 | ESP32 디스플레이 확장 핀 | 설명 |
| :--- | :--- | :--- | :--- |
| **전원 공통** | VCC | **5V** | 디스플레이의 5V 전원 레일 공유 |
| | GND | **GND** | 디스플레이의 접지 레일 공유 |
| **HX711 (로드셀)** | **DT (DOUT)** | **GPIO 2** (또는 보드 가용 IO) | 로드셀 24비트 데이터 라인 |
| | **SCK** | **GPIO 3** (또는 보드 가용 IO) | 로드셀 클록 라인 |
| **MAX7219 (8자리 세그먼트)** | **DIN** | **GPIO 17** (또는 보드 가용 IO) | 시리얼 데이터 라인 |
| | **CLK** | **GPIO 18** (또는 보드 가용 IO) | 시리얼 클록 라인 |
| | **CS** | **GPIO 19** (또는 보드 가용 IO) | Chip Select 라인 |
| **패시브 부저 (선택)** | I/O (+) | **GPIO 10** | 효과음 피에조 부저 |

## 3. 동작 시나리오 및 '띠리리리' 연출

1. **대기 모드 (`STATE_IDLE`)**:
   - 세그먼트에 `--------` 표시
   - LCD 화면에는 대기 사진 출력
2. **손 올림 감지 (`STATE_TRIGGERED`)**:
   - 100mm 원판에 관람객이 손을 얹으면 로드셀 하중(100g 이상) 즉각 감지
   - **동시 실행**:
     - **LCD 디스플레이**: SD 카드의 `/images` 폴더에서 무작위 JPEG 사진을 0.1초 만에 화면 전체에 렌더링
     - **8자리 세그먼트**: 카지노 슬롯머신처럼 전체 숫자가 촤라라락 고속 회전하다가, 왼쪽부터 한 자리씩 '탁! 탁! 탁!' 멈추며 회전 속도가 서서히 느려지는 감속 롤링 애니메이션 재생
     - **사운드**: 부저에서 주파수가 600Hz에서 2400Hz로 상승하는 '띠리리리' 사운드 재생 후 "띵-!" 피날레
3. **손 뗌 감지 (`STATE_WAIT_RELEASE`)**:
   - 손을 떼면 무게가 0g으로 원복되며 다시 대기 모드(`--------`)로 자동 리셋

## 4. Antigravity IDE에서 디스플레이로 펌웨어 업로드하는 방법

Antigravity IDE에는 이미 **PlatformIO IDE**가 설치되어 있으므로, USB 케이블만 꽂으면 IDE 내부에서 원클릭으로 펌웨어를 올릴 수 있습니다.

### [방법 1] PlatformIO 원클릭 업로드 (가장 권장)

1. **디스플레이 연결**:
   - USB-C 케이블로 ESP32 디스플레이 보드를 PC에 연결합니다. (케이블이 '단순 충전용'이 아닌 '데이터 통신용'인지 확인)
2. **PlatformIO 프로젝트 열기**:
   - Antigravity IDE의 탐색기에서 `Interactive_Display` 폴더를 확인합니다.
3. **업로드 실행**:
   - Antigravity IDE 창 최하단의 파란색 상태 표시줄(Status Bar)에 있는 **`→` (PlatformIO: Upload)** 버튼을 클릭합니다.
   - *또는* 좌측 사이드바의 **외계인 얼굴 아이콘(PlatformIO)** 클릭 ➔ `Project Tasks` ➔ `esp32s3_display` ➔ **`Upload`** 클릭!
   - 필요 라이브러리(`LovyanGFX`, `TJpg_Decoder`, `LedControl`, `HX711`)가 자동으로 다운로드되고 빌드 및 플래시 업로드가 진행됩니다.

### [방법 2] 내장 터미널 명령어로 업로드

Antigravity IDE 상단 메뉴 `Terminal` ➔ `New Terminal` (또는 `Ctrl + ~`)을 열고 아래 명령어를 입력합니다:

```powershell
& "C:\Users\passp\.platformio\penv\Scripts\pio.exe" run -d "c:\Users\passp\Desktop\univercity\4-2\머신아트랩\박건작가님\Interactive_Display" --target upload
```

### [방법 3] 기존 설치된 Arduino IDE 2.x 이용 시

PC에 Arduino IDE 2.x도 설치되어 있으므로:
1. `c:\Users\passp\Desktop\univercity\4-2\머신아트랩\박건작가님\Interactive_Display_Arduino\Interactive_Display_Arduino.ino` 파일을 더블클릭하여 Arduino IDE로 엽니다.
2. 보드: `ESP32S3 Dev Module` (또는 `ESP32 Dev Module`) 선택
3. 포트: 연결된 COM 포트 선택
4. 상단 좌측의 `→` (업로드) 버튼 클릭

## 5. MicroSD 카드 세팅 가이드

1. **포맷**: MicroSD 카드를 **FAT32** 형식으로 포맷합니다.
2. **폴더 생성**: SD 카드 최상위 루트에 **`/images`** 폴더를 만듭니다.
3. **사진 저장**:
   - 띄우고 싶은 사진들을 JPEG(`01.jpg`, `02.jpg` 등) 포맷으로 넣습니다.
   - 디스플레이 해상도(예: 800x480, 480x480)에 맞게 리사이즈해 두시면 로딩 속도가 0.05초 수준으로 극대화됩니다.
