배선 확인 체크리스트

VIEWE UEDX80480043E-WB-B · 펌웨어 Interactive_VIEWE/ · 배선도는 배선표_및_다이어그램.html

문서 기준으로 설계는 맞춰 두었지만, 아래 항목은 실물에서만 확인할 수 있는 것들입니다. 위에서부터 순서대로 진행하세요. 체크 표시와 기록한 값은 이 브라우저에 저장됩니다.

A. 부품 실물 확인 (배선 전)

헤더 21번(5V/VBUS) 핀은 WB-B에만 있습니다.
방법: 보드 뒷면 상단의 UEDX80480043E-WB-B 인쇄를 확인하고, J2/J3 헤더가 21핀(맨 아래 VBUS / 5V)인지 봅니다.
제조사마다 핀 이름이 다르고, 5V 전용인지 3.3V도 되는지에 따라 VCC 연결이 달라집니다.
방법: 모듈 뒷면 실크와 제품 설명서에서 다음을 확인합니다.
· VCC 허용 전압 (5V만 / 3.3~5V)
· CS 핀이 있는지 (없는 모듈이면 버스 공유 불가)
· DC(RS/A0), RESET(RST), LED(BLK/BL) 핀 이름
· 온보드 3.3V 레귤레이터/레벨시프터 칩 유무
CS 핀이 없으면: SD·MAX7219와 버스를 공유할 수 없으니 바로 알려주세요(배선 재설계 필요). LED 핀이 5V 전용이면 3.3V 대신 5V 레일에 연결합니다.
기록
방법: 입력 쪽 5핀이 VCC GND DIN CS CLK인지 확인합니다. 반대쪽의 출력 핀(DOUT)은 연결하지 않습니다.
기록
일부 HX711 모듈은 VCC(아날로그)와 VDD(디지털)가 나뉘어 있습니다.
방법: 핀이 GND DT SCK VCC 4개면 VCC를 3.3V에 연결합니다. VDD가 따로 있으면 VCC와 VDD 둘 다 3.3V에 연결합니다. 로드셀 4선 색과 E+/E-/A-/A+ 대응은 키트 설명서로 확인합니다.
기록
방법: 어댑터 라벨이 5V ⎓ 2A 이상인지 봅니다. 케이블은 USB-C(또는 A→C)로 보드 UART 포트에 꽂습니다. 업로드할 때는 데이터 전송이 되는 케이블이어야 합니다.
기록

B. 멀티미터 측정 (부품 연결 전)

가지고 있는 회로도는 헤더 20핀 버전이라 21번 핀이 도면에 나오지 않습니다. MAX7219와 ST7789 전원을 여기서 가져갑니다.
방법: 어댑터를 UART 포트에 꽂아 보드를 켭니다. 멀티미터 DC V 모드로 빨간 리드는 J3 '5V'(맨 아래), 검은 리드는 J3 'GND'(그 위)에 댑니다.
정상: 4.7 ~ 5.2V
0V이거나 값이 이상하면: 이 핀은 쓰지 말고, 5V를 어댑터에서 직접 분기합니다(USB-C 터미널 분기 어댑터 등). GND는 보드와 공통으로 묶습니다.
측정값
방법: 같은 방법으로 '3.3V'–'GND' 사이를 잽니다. 정상: 3.2 ~ 3.4V
측정값
회로도상 이 핀은 터치 INT(CTP_INT)이고, GPIO18과는 R33(미장착일 수 있음)을 거쳐야 연결됩니다. 연결되어 있으면 부저를 달 수 있습니다.
방법: 이 핀에는 3.3V 풀업 저항이 있습니다. 그래서 아래 테스트 코드로 GPIO18을 LOW로 내린 뒤 J2 14번 전압을 재면 됩니다.
0V 근처 → 연결됨(부저 가능) · 3.3V 근처 → 미연결
// Arduino IDE 또는 PlatformIO 새 프로젝트에 넣고 업로드
void setup() { pinMode(18, OUTPUT); digitalWrite(18, LOW); }
void loop() {}
연결되어 있으면: include/pins.h에서 PIN_BUZZER = 18로 바꾸고, 패시브 부저를 J2 14번과 GND 사이에 연결합니다.
측정값

C. 단계별 동작 확인 (하나씩 연결하며)

부품을 꽂거나 뺄 때는 반드시 USB를 뽑은 상태에서 합니다.

방법: Interactive_VIEWE를 업로드하고 시리얼 모니터(115200)를 엽니다.
정상: 4.3" 화면에 "Interactive Art Lab" 문구가 뜹니다. SD카드가 없으면 빨간 SD Card Error!가 뜨는데 이것도 정상입니다. 시리얼에 [HX711] 응답 없음이 나오는 것도 지금은 정상입니다.
화면이 흔들리거나 밀리거나 줄무늬가 생기면: lgfx_displays.h에서 freq_write를 15MHz에서 12MHz로 낮춥니다. 화면이 아예 검으면: 시리얼 로그를 캡처해 공유해 주세요.
결과
방법: 카드를 FAT32로 포맷하고 루트에 images 폴더를 만든 뒤 JPEG를 넣습니다(800×480 권장, 최대 200장). 리셋합니다.
정상: 사진이 뜨고, 시리얼에 [SD] 이미지 N장 등록과 렌더링 시간(ms)이 찍힙니다.
마운트 실패: 32GB 이하 카드로 FAT32 포맷을 다시 하세요. 사진이 깨지면: 프로그레시브 JPEG일 수 있으니 '기본(baseline)' JPEG로 다시 저장하세요.
렌더링 시간
이 설계에서 가장 검증이 필요한 부분입니다. SD카드와 SPI 버스를 실제로 나눠 써도 둘 다 동작하는지 확인합니다.
방법: ST7789를 연결하고 리셋합니다.
정상: 상단 "MACHINE ART LAB" 헤더와 READY, 오른쪽 위 SD N img가 표시되고, 4.3" 화면에도 사진이 계속 뜹니다.
· 색이 반전됨 → invert = false
· 빨강·파랑이 바뀜 → rgb_order = true
· 화면이 거꾸로 → main.cpp의 setRotation(1)을 3으로
· 화면 일부가 지글거림 → offset_x/offset_y 조정(모듈 사양 확인)
· ST7789를 연결한 뒤 SD가 실패하면 → ST7789의 SDO/MISO가 연결되어 있지 않은지 먼저 확인하고, 그래도 안 되면 로그와 함께 알려주세요.
결과
방법: MAX7219를 연결하고 리셋합니다.
정상: 부팅할 때 88888888이 나온 뒤 --------로 바뀝니다.
· 아무것도 안 켜지거나 숫자가 깨짐 → 3.3V 신호 레벨 문제일 가능성이 큽니다. DIN·CLK·CS 3가닥에 74AHCT125 레벨시프터를 넣습니다.
· 자리 순서가 반대 → 알려주세요(코드에서 뒤집기)
· 너무 밝거나 어두움 → SEG_INTENSITY(0~15) 조정
· MAX7219 연결 후 ST7789나 SD가 이상해짐 → 알려주세요
결과
손 올림을 판정하는 기준값 TRIGGER_THRESHOLD(기본 8000)는 실측값을 보고 정해야 합니다.
방법: 원판까지 조립한 상태로 리셋합니다(부팅 시 영점을 잡으므로 이때 손대지 마세요). 정보 LCD의 raw 값과 시리얼 로그를 보며 아래 세 값을 기록합니다.
(1) 아무것도 안 올렸을 때 raw 값이 흔들리는 폭
(2) 손을 가볍게 얹었을 때의 raw 값
(3) 꾹 눌렀을 때의 raw 값
설정 기준: TRIGGER는 (1)보다 충분히 크고 (2)보다 작게, 보통 (2)의 절반 정도로 잡습니다. RELEASE는 TRIGGER의 절반으로 둡니다.
값이 전혀 안 변하면: E+/E-/A+/A- 배선과 HX711 VCC(3.3V)를 확인합니다. 부팅마다 HX711 ERR가 뜨면: DT='17', SCK='38' 핀을 다시 확인합니다.
(1) 노이즈
(2) 가볍게
(3) 꾹 누름

D. 통합·전시 조건 테스트

손 올림 → 사진 전환과 룰렛 → 번호 확정 → 손 뗌 → -------- 복귀. 오작동(손을 안 댔는데 반응 / 손을 댔는데 무반응)이 몇 번 나오는지 셉니다.
결과
PC가 아닌 어댑터로만 켜 둡니다. 재부팅, 화면 깜빡임, 세그먼트 깨짐이 있는지, 시간이 지나며 영점이 틀어져 혼자 반응하는지 봅니다.
재부팅이나 깜빡임이 있으면: 어댑터 용량, 케이블 길이·품질을 확인하고 MAX7219 밝기를 낮춰 봅니다.
결과
BOOT 버튼(GPIO0)이 MAX7219 CS를 겸합니다. 동작 중에 눌리면 세그먼트 표시가 잠깐 깨질 수 있습니다(5초 안에 자동 복구).
케이스나 프레임에 조립했을 때 BOOT/RESET 버튼이 눌리지 않는지 확인합니다.

E. 작가님·팀과 정할 것

현재 배선은 터치 칩의 핀을 재활용하므로 터치가 꺼집니다. 나중에 터치가 필요해지면 배선 재설계가 필요합니다.
결정
지금은 상태 · 하중 막대 · 확정 번호 · 사진 파일명이 나옵니다. 관람객용 연출인지, 설치·점검용 화면인지 정해야 합니다.
결정
필요하면 B-3(GPIO18 연결) 결과에 따라 결정합니다. 미연결이면 시리얼(TX)을 포기하고 GPIO43을 쓰는 방법이 남습니다.
결정
800×480이 아닌 사진은 비율을 유지한 채 화면에 맞추고, 남는 부분은 검은 여백으로 둡니다. 코드상 최대 200장입니다.
결정

확인 결과(특히 A-2, B-1, C-3, C-5의 값)를 알려주시면 코드와 배선도에 반영합니다.
