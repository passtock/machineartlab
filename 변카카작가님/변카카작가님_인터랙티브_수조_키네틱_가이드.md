# [머신아트랩] 변카카 작가님 인터랙티브 수조 키네틱 설치물 가이드

본 문서는 **"수조 같은 공간에 물체를 실로 매달아놓고, 관람객이 레버를 당기면 그에 따라 물체가 유기적으로 움직이는 인터랙티브 키네틱 아트"**를 제작하기 위한 하드웨어 기구 설계, 추천 부품 목록(BOM), 회로 배선도, 그리고 펌웨어 제어 코드를 정리한 가이드입니다.

---

## 1. 작품 컨셉 및 인터랙션 시나리오

```
[관람객 조작]                  [제어기 & 모터]                     [수조 내부]
관람객이 손잡이(레버)를          아두이노/ESP32가 각도 감지 후      투명 낚싯줄로 연결된
당기거나 믐 ──────────────▶   '물 속 점성(댐핑)' 알고리즘 거쳐 ──▶ 오브제가 물속에서 유영하듯
(0~100% 가변 조작)             모터를 부드럽게 구동                스르륵 상하 승강/움직임
```

### 왜 기계식 줄 직결 대신 '전자식 모터 제어'를 쓰는가?
1. **물리적 거리/설치 자유도**: 레버 조작대와 수조가 멀리 떨어져 있어도 전선 하나로 깔끔하게 연결됩니다.
2. **물리 점성/부력 시뮬레이션**: 관람객이 레버를 거칠게 '팍!' 당겨도, 소프트웨어 필터(EMA Damping)를 통해 물체는 마치 **물속의 저항을 받듯이 우아하고 느리게 가감속하며 움직이는 예술적 연출**이 가능합니다.
3. **안전성 (줄 끊김 방지)**: 소프트웨어적으로 상한선/하한선을 고정하므로, 관람객이 무리하게 레버를 당겨도 실이 끊어지거나 모터가 과부하되지 않습니다.

## 2. 하드웨어 메커니즘 2가지 방식 비교

| 구분 | **타입 A. 고토크 서보모터 방식 (추천)** | **타입 B. 스텝모터 + 윈치 방식** |
| :--- | :--- | :--- |
| **적합한 수조 깊이** | **10cm ~ 25cm 내외** (중소형 수조) | **30cm ~ 100cm 이상** (대형/깊은 수조) |
| **장점** | 구조가 매우 단순함, 별도 드라이버 불필요, 조립 1시간 컷 | 이동 거리가 무제한, 정숙함(TMC2208 무소음) |
| **단점** | 180도 회전 한계 (풀리 지름에 따라 이동거리 결정) | 원점 리밋 스위치 필요, 드라이버 배선 필요 |
| **핵심 모터** | MG996R 또는 DS3218 (20kg 메탈기어 서보) | NEMA 17 스텝모터 + TMC2208 저소음 드라이버 |
| **준비된 코드** | `src/Kinetic_WaterTank_Servo/` | `src/Kinetic_WaterTank_Stepper/` |

> 💡 **추천**: 수조 깊이가 25cm 이하라면 **타입 A(서보모터)**로 시작하시는 것이 제작 난이도와 안정성 면에서 가장 좋습니다. 만약 수조가 크고 깊다면 **타입 B(스텝모터)**를 선택하세요.

## 4. 시스템 회로 배선도 (서보모터 기준)

```mermaid
flowchart LR
    subgraph Power["외부 전원 (5V 3A)"]
        PWR_5V[5V +]
        PWR_GND[GND -]
    end

    subgraph MCU["아두이노 (Arduino Uno / Nano)"]
        A0[A0 핀]
        D9[D9 핀]
        D6[D6 핀]
        ARD_GND[GND]
    end

    subgraph Lever["관람객 조작 레버"]
        POT_VCC[VCC (+5V)]
        POT_OUT[신호 출력]
        POT_GND[GND]
    end

    subgraph Actuator["구동부 & 수조 연출"]
        SERVO[MG996R 서보모터\n(실 감기/풀기)]
        LED[수조 라이팅 LED]
    end

    PWR_5V --> POT_VCC
    PWR_5V --> SERVO
    PWR_GND --> ARD_GND
    PWR_GND --> POT_GND
    PWR_GND --> SERVO

    POT_OUT -->|레버 당김 각도| A0
    D9 -->|PWM 신호| SERVO
    D6 -.->|수심 연동 밝기| LED
```
