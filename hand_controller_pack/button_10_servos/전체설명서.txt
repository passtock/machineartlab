================================================================================
  손 로봇 제어 통합 패키지 (다른 PC 이동용) 사용 설명서
================================================================================

본 압축 파일은 다른 컴퓨터에서도 추가 설정이나 에러 없이 바로 작업할 수 있도록
모든 필요 파일과 라이브러리를 한 곳에 모아둔 통합 패키지입니다.

--------------------------------------------------------------------------------
■ 폴더 및 파일 구성
--------------------------------------------------------------------------------

1. [button_10_servos] 폴더 (★신규 제작 버튼 제어 스케치)
   - button_10_servos.ino : 2핀 버튼을 누르면 10개 서보가 동시 동작하는 코드
   - README.txt / 사용설명서.txt : 배선 및 상세 사용법
   ※ 기본 내장 <Servo.h> 사용으로 별도 라이브러리 설치 없이 바로 컴파일/업로드 가능!

2. [handv.0] 폴더 (센서 기반 원본 스케치)
   - handv.0.ino : 10개 센서 입력을 받아 10개 서보를 제어하는 원본 스케치
   - AverageValue.h : 컴파일 에러 해결을 위해 폴더 내에 함께 동봉된 헤더 파일

3. [VarSpeedServo-master.zip]
   - handv.0 스케치 또는 서보 속도 조절 기능에 필요한 아두이노 라이브러리 압축 파일


--------------------------------------------------------------------------------
■ 다른 컴퓨터에서 사용하는 방법
--------------------------------------------------------------------------------

[1] 새 버튼 스케치(button_10_servos)를 사용할 때:
    1) 'button_10_servos' 폴더 안의 'button_10_servos.ino'를 아두이노 IDE로 엽니다.
    2) [툴] -> [보드]에서 아두이노 보드 선택 (예: Arduino Mega)
    3) [툴] -> [포트]에서 연결된 COM 포트 선택
    4) [업로드] 클릭! (추가 라이브러리 설치 필요 없음)

[2] 기존 스케치(handv.0)를 사용할 때:
    1) 아두이노 IDE 상단 메뉴 [스케치] -> [라이브러리 포함하기] -> [.ZIP 라이브러리 추가...] 클릭
    2) 본 폴더에 있는 'VarSpeedServo-master.zip' 파일을 선택하여 등록
    3) 'handv.0' 폴더 안의 'handv.0.ino'를 열고 [업로드] 클릭!


--------------------------------------------------------------------------------
■ 2핀 푸시 버튼 배선 안내 (button_10_servos 기준)
--------------------------------------------------------------------------------
- 버튼 선 1  --> 아두이노 GND (그라운드)
- 버튼 선 2  --> 아두이노 A0 핀 (내부 풀업 INPUT_PULLUP 적용으로 외장 저항 불필요)
- 서보 10개  --> 디지털 2번 ~ 11번 핀
- 전원 제어  --> 디지털 12번 핀
