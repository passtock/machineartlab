================================================================================
  10-Servo 2-Pin Button Controller (button_10_servos) Manual / 사용 설명서
================================================================================

본 프로그램은 2핀 푸시 버튼을 누르면 10개의 서보 모터(손/손가락)가 동시에 
부드럽게 동작하도록 제작된 아두이노 스케치입니다.
아두이노 기본 내장 라이브러리(<Servo.h>)만 사용하므로, 다른 컴퓨터로 옮겨도
추가 라이브러리 설치 없이 바로 열어서 업로드할 수 있습니다.


--------------------------------------------------------------------------------
1. 하드웨어 배선(연결) 방법
--------------------------------------------------------------------------------

[1] 2핀 푸시 버튼 연결 (저항 불필요! 내부 풀업 INPUT_PULLUP 적용)
    - 버튼 핀 1  --> 아두이노 GND (그라운드)
    - 버튼 핀 2  --> 아두이노 A0 핀 (디지털 입력 핀)
    ※ 메가(Mega), 우노(Uno), 나노(Nano) 모두 A0 핀을 디지털 입력으로 사용 가능합니다.
      (다른 디지털 핀으로 바꾸고 싶다면 코드 28번째 줄 BUTTON_PIN 번호만 수정)

[2] 서보 모터 10개 신호선(주황/노랑/하양선) 연결
    - 왼손 5개  : 디지털 2, 3, 4, 5, 6 번 핀
    - 오른손 5개: 디지털 7, 8, 9, 10, 11 번 핀

[3] 서보 모터 전원 제어 핀 (릴레이 또는 전원 차단용)
    - 디지털 12 번 핀 (기본값: LOW 일 때 전원 공급)

[4] ★전원 주의사항★
    - 서보 모터가 10개이므로 아두이노 보드의 5V 핀에 직접 전원을 공급하면
      전류 부족으로 아두이노가 꺼지거나 리셋될 수 있습니다.
    - 서보 모터의 VCC(빨강), GND(갈색/검정)는 반드시 '외부 5V 전원 어댑터/배터리'에
      연결하시고, 외부 전원의 GND와 아두이노 GND를 서로 연결(공통 접지)해 주세요.


--------------------------------------------------------------------------------
2. 다른 컴퓨터에서 사용하는 방법
--------------------------------------------------------------------------------

1) 제공된 'button_10_servos.zip' 압축 파일을 다른 컴퓨터에 복사합니다.
2) 압축을 풀면 'button_10_servos' 폴더가 나옵니다.
   (주의: 아두이노는 폴더 이름과 파일 이름이 같아야 합니다.)
3) 폴더 안의 'button_10_servos.ino' 파일을 더블 클릭하여 아두이노 IDE로 엽니다.
4) 상단 메뉴 [툴] -> [보드] 에서 사용 중인 보드 선택 (예: Arduino Mega 또는 Uno)
5) [툴] -> [포트] 에서 연결된 COM 포트 선택
6) [업로드] (화살표 모양 버튼) 클릭!
   - 추가 라이브러리 설치 없이 100% 한 번에 컴파일/업로드됩니다.


--------------------------------------------------------------------------------
3. 코드 설정 커스터마이징 (필요에 따라 변경)
--------------------------------------------------------------------------------

[동작 모드 변경] (코드 55번째 줄 MOTION_MODE)
  - MODE 1 (기본값): 버튼을 누르고 있는 동안 손가락을 쥐고, 손을 떼면 펴짐
  - MODE 2        : 버튼을 한 번 누를 때마다 쥔 상태 <-> 펴진 상태 토글 전환
  - MODE 3        : 버튼을 누르면 자동으로 쥐었다가 1초 후 펴지는 1회 사이클

[서보 각도 변경] (코드 40~50번째 줄)
  - REST_ANGLES  : 버튼을 안 눌렀을 때의 펴진 각도 (기본 0도)
  - ACTIVE_ANGLES: 버튼을 눌렀을 때의 쥔 각도 (100도 ~ 180도)

[움직임 속도 조절] (코드 60번째 줄 STEP_DELAY_MS)
  - 기본값은 15 (ms)입니다.
  - 숫자를 더 크게 하면(예: 30) 천천히 부드럽게 움직이고,
    숫자를 더 작게 하면(예: 5) 빠르게 움직입니다.
