================================================================================
  10-Servo 2-Pin Button Controller (button_10_servos) Manual / 사용 설명서
================================================================================

본 프로그램은 2핀 푸시 버튼을 누르고 있는 동안 10개의 서보 모터(손/손가락)가
실시간으로 쥐어지고, 손을 떼면 즉시 펴지도록 제작된 아두이노 스케치입니다.

기존 방식과 달리 delay()로 멈추지 않는 논블로킹(Non-blocking) 방식으로 동작하여,
버튼을 쥐는 도중에 떼더라도 중간 각도에서 즉시 펴지는 방향으로 부드럽게 반응합니다.

아두이노 기본 내장 라이브러리(<Servo.h>)만 사용하므로, 다른 컴퓨터로 옮겨도
추가 라이브러리 설치 없이 바로 열어서 업로드할 수 있습니다.


--------------------------------------------------------------------------------
1. 하드웨어 배선(연결) 방법
--------------------------------------------------------------------------------

[1] 2핀 푸시 버튼 10개 연결 (저항 불필요! 내부 풀업 INPUT_PULLUP 적용)
    - 모든 버튼 핀 1 --> 아두이노 GND (공통 그라운드)
    - 버튼 핀 2 (신호선) 각각 연결:
        * 왼손 5개  (SG1 ~ SG5) : 아날로그 A0, A3, A4, A10, A11 핀
        * 오른손 5개 (SD1 ~ SD5) : 아날로그 A5, A6, A7, A8, A9 핀
    ※ 각 손가락 버튼을 누르면 해당 손가락만 개별적으로 쥐어집니다.

[2] 서보 모터 10개 신호선(주황/노랑/하양선) 연결
    - 왼손 5개  : 디지털 2, 3, 4, 5, 6 번 핀 (SG1 ~ SG5)
    - 오른손 5개: 디지털 7, 8, 9, 10, 11 번 핀 (SD1 ~ SD5)

[3] 서보 모터 전원 제어 핀 (릴레이 또는 전원 차단용)
    - 디지털 12 번 핀 (LOW 일 때 전원 ON)

[4] ★전원 주의사항★
    - 서보 모터가 10개이므로 아두이노 보드의 5V 핀에 직접 전원을 공급하면
      전류 부족으로 아두이노가 꺼지거나 리셋될 수 있습니다.
    - 서보 모터의 VCC(빨강), GND(갈색/검정)는 반드시 '외부 5V 전원 어댑터/배터리'에
      연결하시고, 외부 전원의 GND와 아두이노 GND를 서로 연결(공통 접지)해 주세요.


--------------------------------------------------------------------------------
2. 서보 각도 및 동작 기준
--------------------------------------------------------------------------------

[펴진 상태 (기본 시작 위치, OPEN_ANGLES)]
  - 왼손  : 0, 0, 0, 0, 0
  - 오른손: 100, 100, 120, 100, 120 (시작 각도)

[쥔 상태 (버튼 누름 시 목표 위치, CLOSE_ANGLES)]
  - 왼손  : 150, 150, 150, 150, 180
  - 오른손: 0, 0, 0, 0, 0 (0도로 갈수록 쥐어짐)

[움직임 속도 조절 (STEP_DELAY_MS)]
  - 기본값은 15 (ms)입니다. (1도 이동 간격)
  - 숫자를 더 크게 하면(예: 25) 천천히 부드럽게 움직이고,
    숫자를 더 작게 하면(예: 8) 빠르게 반응합니다.
